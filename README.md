# Four Fold Event Management

A responsive, premium black-and-gold landing page for Four Fold Event Management.

## Website
- `index.html` — responsive single-page site with services, gallery, planning process and enquiry form.
- `assets/fourfold-logo.png` — brand logo used in the header and footer.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment. The public site address will appear in that settings page.

The repository includes a GitHub Actions Pages workflow; if it is configured to deploy with GitHub Actions, use the workflow's deployment instructions instead.

## Important before launch
- Add your official WhatsApp number in `index.html` by replacing the empty `WHATSAPP_NUMBER` value with the country code and phone digits only (for India, `91XXXXXXXXXX`). Until configured, the form will not open a WhatsApp enquiry.
- Replace the sample imagery with your own event portfolio when available. The current visual images load from Unsplash and require an internet connection.
- Update contact details and social links as your official channels are confirmed.
