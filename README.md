# Four Fold Event Management

A responsive, premium black-and-gold landing page for Four Fold Event Management.

## Website files
- `index.html` — responsive single-page site with services, gallery, planning process and enquiry form.
- `assets/fourfold-logo.svg` — local SVG emblem created to match the black-and-gold brand theme and displayed in the header/footer.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **GitHub Actions** if not already selected.
3. The included workflow at `.github/workflows/static.yml` deploys automatically on pushes to `main`.
4. After the workflow succeeds, open **Settings → Pages** to find the live URL.

## Important before launch
- Replace the illustrative SVG emblem with your original uploaded PNG for an exact match. The current SVG is a brand-coloured approximation, not the original uploaded logo file.
- Add your business WhatsApp number in `index.html` by replacing the empty `WHATSAPP_NUMBER` value with the country code and phone digits only (India: `91XXXXXXXXXX`). Until configured, the enquiry form will not open a WhatsApp message.
- Replace sample images from Unsplash with your own event portfolio when available. They require an internet connection.
- Add confirmed phone, address and social links before launch.
